# Color Changer

A small browser-based app that changes the page background to a randomly generated color. The current color is shown on the page in hexadecimal notation.

## Features

- Generate a new six-digit hexadecimal color with one click.
- Update the page background and displayed color value together.
- Animate background-color changes with a short CSS transition.
- Run directly in a modern web browser without installing packages or building the project.

## Requirements

- A modern web browser with JavaScript enabled.
- No frameworks, package manager, or external dependencies are required.

## Getting started

1. Download or clone this project.
2. Open `index.html` in a web browser.
3. Select **Change Color** to generate and apply a new background color.

Alternatively, serve the project directory with any static web server and open the local address it provides. A server is not required for this app.

## How to use

When the page loads, it displays a color value and a **Change Color** button. Each click generates a color in `#RRGGBB` format, applies it as the document background, and replaces the displayed value with the generated color. The background transitions smoothly between colors.

The color is generated by choosing six characters independently from the hexadecimal digits `1`–`9` and `A`–`F`. The resulting value is a valid six-digit hexadecimal color. Since each digit is selected at random, the same color can appear more than once.

## Project structure

| File | Purpose |
| --- | --- |
| `index.html` | Defines the page content and loads the stylesheet and JavaScript. |
| `styles.css` | Provides the centered layout, button styling, and background transition. |
| `script.js` | Generates random colors and updates the background and color label when the button is clicked. |

## Customization

- **Change the initial background:** Edit the `background-color` value in the `body` rule in `styles.css`.
- **Change the initial displayed value:** Edit the text inside the `#color-text` element in `index.html`.
- **Change the generated color characters:** Edit the `hexCharacters` array in `script.js`. Keep the array limited to hexadecimal digits (`0`–`9` and `A`–`F`) to produce valid hex colors.
- **Adjust the transition:** Change the `transition` duration or easing in the `body` rule in `styles.css`.
- **Restyle the interface:** Update the `.container` and `.btn` rules in `styles.css`.

## Development notes
